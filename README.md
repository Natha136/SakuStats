# 💰 SakuStats

SakuStats is an Android personal finance management application developed using Java and Firebase. The application helps users track income and expenses, monitor savings goals, and visualize financial data through an intuitive interface.

## ✨ Features

- 🔐 User Authentication (Firebase Authentication)
- 👤 Edit Profile
- 💵 Income & Expense Management
- 📜 Transaction History
- 📊 Financial Statistics
- 🎯 Savings Plan Management
- ➕ Add Funds to Savings Plans
- ➖ Withdraw Funds from Savings Plans
- 🔔 Notifications
- ☁️ Cloud Database using Firebase Firestore

## 🛠 Tech Stack

- Java
- Android Studio
- Firebase Authentication
- Firebase Firestore
- Glide
- Material Design Components

## 🚀 Getting Started

### Prerequisites

- Android Studio
- JDK 17+
- Firebase Project
- Android Device or Emulator

### Installation

1. Clone this repository

```bash
git clone https://github.com/yourusername/SakuStats.git
```

2. Open the project in Android Studio.

3. Connect your Firebase project by adding your own `google-services.json`.

4. Sync Gradle.

5. Run the application.
